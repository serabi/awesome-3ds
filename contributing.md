# Contribution Guidelines

Thanks for helping grow the list.

## Suggesting a project

Not sure how to edit the list yourself? [Open a suggestion issue](https://github.com/serabi/awesome-3ds/issues/new?template=suggest-a-project.yml) with a link and a short description, and it can be added for you.

## Opening a pull request

1. Fork this repository and create a branch, for example `add-sv3ds`.
2. Edit `README.md` and add your entry at the bottom of the right section.
3. Optional: run `npx awesome-lint` to check the formatting.
4. Open a pull request titled `Add Project Name` and fill in the checklist.

## Adding an entry

- Link to the source repository when there is one. Otherwise link to the release page.
- Use the format `- [Name](link) - Description.` Keep the description short, start it with a capital letter and end it with a period.
- End the description with "(New 3DS only)" if the project needs a New 3DS.
- Add new entries at the bottom of their section.
- One project per pull request, please.

## What fits

- Homebrew that runs on the 3DS family, plus tools and resources for it.
- Projects that are playable or usable today. Early work in progress is welcome once there is a release.

## What doesn't fit

- ROMs, CIAs of retail games, or links to sites that host them.
- Tools that need leaked SDKs or cracked software to build.
- Repositories that only contain a README or a download link with no source or project history.
